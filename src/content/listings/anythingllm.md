<h2 class="ace-line ace-line old-record-id-WJ36dN6q8o9jm6xxTwCcNRxPnRF">What Is AnythingLLM?</h2>
<div class="ace-line ace-line old-record-id-EchRfbao3dAogDcm2xJckJLMnIg">AnythingLLM is an open-source platform designed to help teams build private AI workspaces using either local or hosted models. It offers a practical, user-friendly solution for chatting with documents, integrating various knowledge sources, and running AI assistants in a self-hosted environment—eliminating full reliance on closed SaaS (Software as a Service) tools. Whether for privacy-focused teams or those seeking more control over their AI workflows, AnythingLLM bridges the gap between functionality and data autonomy.</div>
<h2 class="heading-2 ace-line old-record-id-YBd2fNqoKddlUscvVN8cKDRLn5s">Key Features and Capabilities</h2>
<div class="ace-line ace-line old-record-id-TAAQfI3OrdvZaFcAj0YcbEsbnse">AnythingLLM equips modern users and teams with a comprehensive set of AI tools tailored for practical use cases:</div>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-WLUwfePo8dwrkUc6bNQczqoMnah" data-list="bullet">
<div><strong>Private Document Chat</strong> – Create dedicated workspaces where you can upload files and knowledge sources, then chat with them to get accurate, context-aware answers—ideal for internal documentation, research materials, or confidential data.</div>
</li>
<li class="ace-line ace-line old-record-id-LE6TfEguNdmPFCc5QYGc66QjnEe" data-list="bullet">
<div><strong>Local and Hosted Model Support</strong> – Seamlessly integrates with Ollama, OpenAI-compatible APIs, and other model backends, giving you the flexibility to use local models (for maximum privacy) or hosted models (for convenience).</div>
</li>
<li class="ace-line ace-line old-record-id-XVv5fmh6UdGd1ZcuNNecsxzYnBf" data-list="bullet">
<div><strong>RAG-Ready Architecture</strong> – Built specifically for retrieval-augmented generation (RAG) workflows, enabling efficient retrieval of information from company knowledge bases and internal documents to power more accurate AI responses.</div>
</li>
<li class="ace-line ace-line old-record-id-KXqgfzjqIdyVzaclmB2cniSFngb" data-list="bullet">
<div><strong>Self-Hosted Deployment</strong> – Perfect for privacy-sensitive teams that need full control over their data, as it can be deployed on your own servers or cloud infrastructure, keeping sensitive information in-house.</div>
</li>
<li class="ace-line ace-line old-record-id-O9hTfjIW5dtJDvc4TvacHsQpnZe" data-list="bullet">
<div><strong>Multi-User Workspace Design</strong> – Organize AI assistants, data sources, and projects into separate workspaces, making it easy for teams to collaborate, manage permissions, and stay focused on specific tasks.</div>
</li>
<li class="ace-line ace-line old-record-id-ENYhfQboQdYd4VcgbLuc2BEIn4g" data-list="bullet">
<div><strong>Agent and Tool Expansion</strong> – Serves as a robust foundation for building broader internal AI assistant systems, allowing you to extend functionality with custom agents and integrate additional tools as your needs grow.</div>
</li>
</ul>
<h2 class="heading-2 ace-line old-record-id-TPWCfX3gxdsy8PczvQgcWy4lnbq">Pricing Plans</h2>
<div class="ace-line ace-line old-record-id-RgA9fCZG3dHXJhcYcLDcVzkNnYe">AnythingLLM is completely open-source and free to deploy. The actual cost of using the platform depends on three key factors: your hosting setup (e.g., on-premises servers, cloud providers like AWS/Azure/GCP), storage usage (for uploaded documents and model data), and whether you use local models (free, but requires hardware resources) or connect to paid APIs (e.g., OpenAI, Anthropic)—which incur their own usage fees.</div>
<h2 class="heading-2 ace-line old-record-id-C4oGfEUpid4tNwc2EZicejRqn9g">Who Should Use AnythingLLM?</h2>
<div class="ace-line ace-line old-record-id-QxCKfKkhZd7NFgcnmc3c5InCnSY">AnythingLLM is particularly well-suited for:</div>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-OSzefgUWDd0edmcRZ1ScWEvUn9c" data-list="bullet">
<div>Startups and small-to-medium businesses (SMBs) looking to build internal knowledge assistants without the high cost of closed SaaS tools.</div>
</li>
<li class="ace-line ace-line old-record-id-HxIcfFQvkd0Z3Mcs2Grcey5dnvh" data-list="bullet">
<div>Internal operations (ops) teams that need a centralized platform to manage and query internal documentation, policies, or process guides.</div>
</li>
<li class="ace-line ace-line old-record-id-J2MyfhgBNdrqgCcHZoBc8NgMnGc" data-list="bullet">
<div>Privacy-conscious organizations (e.g., healthcare, finance, legal) that handle sensitive data and require full control over where their information is stored and processed.</div>
</li>
<li class="ace-line ace-line old-record-id-UCwZfFYZBdCzYTcAJzgc4oQmnJv" data-list="bullet">

</li>
</ul>
<h2 class="heading-2 ace-line old-record-id-H5qCfvDOidxrDDcBqdUcOtkSn8K">AnythingLLM vs Open WebUI vs PrivateGPT</h2>
<div class="ace-line ace-line old-record-id-AUrWfgxrCdRNYoc19pJcIwo7n4b">While all three tools focus on private AI and self-hosting, they differ in their core focus and use cases:</div>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-WzD0fzG4TdpMZvcyW7Xcp3Xandg" data-list="bullet">
<div><strong>AnythingLLM</strong>: Focuses on <em>team collaboration</em>, robust RAG workflows, and broad model compatibility. It’s designed to be a all-in-one workspace for teams, balancing usability, privacy, and functionality.</div>
</li>
<li class="ace-line ace-line old-record-id-WeZKf9Mv2dblnocIz3wcXcSxn3e" data-list="bullet">
<div><strong>Open WebUI</strong>: Primarily a user-friendly interface for chatting with local models. It excels at simple, single-user local model interactions but lacks the team-focused workspace and RAG features of AnythingLLM.</div>
</li>
<li class="ace-line ace-line old-record-id-WanqfcsfCdrJTVcQbgbcS4vFnph" data-list="bullet">
<div><strong>PrivateGPT</strong>: Narrowly focused on private document reasoning and local RAG. It’s great for individual users or small teams needing basic document Q&amp;A but is less flexible for multi-user collaboration or tool expansion.</div>
</li>
</ul>
<div class="ace-line ace-line old-record-id-F3qffZvaqdfFRYcf8cTcB54ynof">For teams seeking a balanced mix of usability, self-hosting control, and knowledge-base workflows, AnythingLLM is the most compelling choice.</div>
<h2 class="heading-2 ace-line old-record-id-C2b8fqyY2dQ3rqckqTGcRBuonoh">Step-by-Step Usage Tutorial</h2>
<div class="ace-line ace-line old-record-id-Ou66fszQVdDQNbc8iMAcDghFnog">This tutorial will guide you through the basic setup and usage of AnythingLLM, from deployment to chatting with your first document.</div>
<h3 class="heading-3 ace-line old-record-id-BGSNfD1avdP0Wic0XGvc17vvn6b">Prerequisites</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-TGaOf4xJWdtk9HcbJX5cLtkBngh" data-list="bullet">
<div>A server or local machine with Docker installed (recommended for easy deployment; alternatively, you can deploy from source code).</div>
</li>
<li class="ace-line ace-line old-record-id-RtlAfrXVCdrPAFcecb4cntlgntc" data-list="bullet">
<div>Basic command-line knowledge (for deployment).</div>
</li>
<li class="ace-line ace-line old-record-id-Uqemfk5qHdl5FQcIhJscYY2ZnVf" data-list="bullet">
<div>Optional: Access to local models (e.g., Ollama) or API keys for hosted models (e.g., OpenAI).</div>
</li>
</ul>
<h3 class="heading-3 ace-line old-record-id-HRKJfcEeVdXKbRcpxxucksA8nn8">1. Deploy AnythingLLM</h3>
<div class="ace-line ace-line old-record-id-SeG0fad2mdmYT5cMeXIclRDFnhf">The easiest way to deploy AnythingLLM is using Docker. Follow these steps:</div>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-Elj7fW57cdfg9AcJSgYcdovbnMc" data-list="number">
<div>Open your command-line terminal and pull the official AnythingLLM Docker image: <code>docker pull mintplexlabs/anythingllm:latest</code></div>
</li>
<li class="ace-line ace-line old-record-id-Jn4xfCMp9dUjkLcUAD5csBKxn7b" data-list="number">
<div>Create a volume to persist your data (workspaces, documents, settings) across container restarts: <code>docker volume create anythingllm_data</code></div>
</li>
<li class="ace-line ace-line old-record-id-JB6kfMAYFdDkWhcJ8mLcQYutn8c" data-list="number">
<div>Run the Docker container (replace <code>YOUR_PORT</code> with a port you want to use, e.g., 3000): <code>docker run -d -p YOUR_PORT:3000 -v anythingllm_data:/app/data mintplexlabs/anythingllm:latest</code></div>
</li>
<li class="ace-line ace-line old-record-id-VCW2fWlt6dFsWlcBuF1ceBTonjh" data-list="number">
<div>Open your web browser and navigate to <code>http://localhost:YOUR_PORT</code> (or your server’s IP address + port). You’ll be prompted to create an admin account to access the platform.</div>
</li>
</ol>
<h3 class="heading-3 ace-line old-record-id-Kk10f89cjdynsycCWUacPmeqntd">2. Create a Workspace</h3>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-IzsWfchzAdKfuScCk1vckNqAnMh" data-list="number">
<div>After logging in, click the &#8220;Create Workspace&#8221; button in the top-right corner.</div>
</li>
<li class="ace-line ace-line old-record-id-SkL7fnu4qdqUwZc1gYKc1yapn1g" data-list="number">
<div>Enter a name for your workspace (e.g., &#8220;Marketing Team Docs&#8221;) and a brief description (optional).</div>
</li>
<li class="ace-line ace-line old-record-id-BITifeg66dQHRzc68vxc02EInZd" data-list="number">
<div>Click &#8220;Create&#8221; to finish setting up your workspace. You’ll be redirected to the workspace dashboard.</div>
</li>
</ol>
<h3 class="heading-3 ace-line old-record-id-B4V4fgVBVdKzfScxQ2XcXnY3nfc">3. Add Knowledge Sources (Documents)</h3>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-FXP3fQpUodsw6dcznAEcRAlJnec" data-list="number">
<div>In your workspace, click the &#8220;Add Knowledge Source&#8221; button.</div>
</li>
<li class="ace-line ace-line old-record-id-VuqYfXdMIdGQCSclCVxcYFvQn6c" data-list="number">
<div>Select the type of source you want to add:</div>
<ol class="list-number2">
<li class="ace-line ace-line old-record-id-P481fpDexdzgr0c61Tuc8UOEnSh" data-list="bullet">
<div><strong>Upload Files</strong>: Supports PDF, DOCX, TXT, Markdown, and other common document formats. Drag and drop files or click to upload.</div>
</li>
<li class="ace-line ace-line old-record-id-Zr6Nfu2XBdxpvWckV3dcJvd7nke" data-list="bullet">
<div><strong>Connect APIs</strong> (optional): Link to external knowledge sources (e.g., Notion, Confluence) via APIs for automated syncing.</div>
</li>
</ol>
</li>
<li class="ace-line ace-line old-record-id-QFOEfWECOdCldVcUhHWcRP63nDh" data-list="number">
<div>After uploading files, AnythingLLM will process and index them (this may take a few minutes, depending on file size and quantity).</div>
</li>
</ol>
<h3 class="heading-3 ace-line old-record-id-YyxcfZ9HfdIL2jcON80cvKubn2C">4. Configure AI Models</h3>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-ITaNfkr8hdiYOVcM8tNcMkYjnAd" data-list="number">
<div>Go to the &#8220;Settings&#8221; tab in your workspace.</div>
</li>
<li class="ace-line ace-line old-record-id-Aq8Sfk8F6dSqc0cwUtrcfgFanAg" data-list="number">
<div>Under &#8220;Model Configuration&#8221;, choose your preferred model backend:</div>
<ol class="list-number2">
<li class="ace-line ace-line old-record-id-P8Tmf3qygdOMHcczlk4cgLGpnRh" data-list="bullet">
<div><strong>Local Models</strong>: If you’re using Ollama, enter the Ollama server URL (e.g., <code>http://localhost:11434</code>) and select the model you want to use (e.g., llama3:8b).</div>
</li>
<li class="ace-line ace-line old-record-id-FyYXfHdwSdTpaDcA78GcwEDDnyf" data-list="bullet">
<div><strong>Hosted Models</strong>: Enter your API key for OpenAI, Anthropic, or other compatible services, and select the model (e.g., gpt-4o).</div>
</li>
</ol>
</li>
<li class="ace-line ace-line old-record-id-A58Hfn1Afd6bOGcgfbicw1V7nsg" data-list="number">
<div>Click &#8220;Save Settings&#8221; to apply your model choice.</div>
</li>
</ol>
<h3 class="heading-3 ace-line old-record-id-F0y9foYLAdDGo7c39s8chSVjnYZ">5. Chat with Your Documents</h3>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-OLeQfX46WdCj1LcjlfAcjheInyg" data-list="number">
<div>Return to your workspace dashboard and click the &#8220;Chat&#8221; tab.</div>
</li>
<li class="ace-line ace-line old-record-id-Ms5qfj7MQd3YFVcs4uFcR7yznPb" data-list="number">
<div>Type a question related to your uploaded documents (e.g., &#8220;What are the key points in the Q3 marketing report?&#8221;).</div>
</li>
<li class="ace-line ace-line old-record-id-CY3CfrEIKd2kxgcDHAzcZgNinNc" data-list="number">
<div>Click &#8220;Send&#8221;—AnythingLLM will retrieve relevant information from your knowledge sources and generate a context-aware response.</div>
</li>
<li class="ace-line ace-line old-record-id-VGQlfKTd7dhUNxcJwkbcfFLpngc" data-list="number">
<div>You can continue the conversation by asking follow-up questions, or switch to a different document by selecting it from the &#8220;Knowledge Sources&#8221; sidebar.</div>
</li>
</ol>
<h3 class="heading-3 ace-line old-record-id-CxovfAnsxdVKwbc1mZScWEGQnFf">6. Invite Team Members (Multi-User Setup)</h3>
<ol class="list-number1" start="1">
<li class="ace-line ace-line old-record-id-KV5QfFSjRdn6vVcAqEwcRvfXnJg" data-list="number">
<div>Go to the &#8220;Workspace Settings&#8221; tab and click &#8220;Invite Members&#8221;.</div>
</li>
<li class="ace-line ace-line old-record-id-JTdrfOx2kd6aOYcJBXucbBBfnhk" data-list="number">
<div>Enter the email addresses of the team members you want to invite and assign roles (e.g., Admin, Editor, Viewer).</div>
</li>
<li class="ace-line ace-line old-record-id-Po1Yf6vsndSbJpcr0pcc5rvsnFg" data-list="number">
<div>Click &#8220;Send Invites&#8221;—team members will receive an email with a link to join the workspace.</div>
</li>
</ol>
<h2 class="heading-2 ace-line old-record-id-DgywfAZRedtuFecHIvrcagCEnve">Important Notes &amp; Best Practices</h2>
<h3 class="heading-3 ace-line old-record-id-JXGgfqhNcdLhY1cGaiFcxEdcnIg">1. Privacy &amp; Data Security</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-LbnIfAg4idKCnZc7l3BcvDCXnPd" data-list="bullet">
<div><strong>Self-Hosting Responsibility</strong>: If you deploy AnythingLLM on your own server, ensure the server is secured (e.g., firewalls, encryption) to protect sensitive data. Avoid exposing the platform to public networks unless necessary.</div>
</li>
<li class="ace-line ace-line old-record-id-IL5sfLZEXd2YHOcJtS2cIWPSnmx" data-list="bullet">
<div><strong>API Key Protection</strong>: When using hosted models (e.g., OpenAI), never share your API keys publicly or store them in unencrypted files. Use environment variables or the platform’s built-in secret management to keep keys secure.</div>
</li>
<li class="ace-line ace-line old-record-id-TiNYftZx6dFlpIcdZ85cBP76n4f" data-list="bullet">
<div><strong>Data Retention</strong>: Regularly back up your workspace data (via the Docker volume or platform export feature) to prevent data loss. Delete unused documents or workspaces to reduce storage costs and improve performance.</div>
</li>
</ul>
<h3 class="heading-3 ace-line old-record-id-UiysfCsQmdgebdcVeDBcKZ6fnif">2. Performance Optimization</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-CyR9fvMPcddtHacQl6ucq5wpnGe" data-list="bullet">
<div><strong>Local Model Hardware Requirements</strong>: Running local models (e.g., llama3:70b) requires significant CPU/GPU resources. For smooth performance, use a machine with a dedicated GPU (NVIDIA GPUs are recommended for faster inference).</div>
</li>
<li class="ace-line ace-line old-record-id-OlNefXnledpbyzcUdCrclHl1n6D" data-list="bullet">
<div><strong>Document Size Limits</strong>: Avoid uploading extremely large files (e.g., 100MB+ PDFs) as they may slow down indexing and chat responses. Split large documents into smaller chunks before uploading.</div>
</li>
<li class="ace-line ace-line old-record-id-ONkOfnUv0d4MuGcJYuzcHdHwntc" data-list="bullet">
<div><strong>Indexing Frequency</strong>: If you’re syncing external knowledge sources (e.g., Notion), set a reasonable sync frequency (e.g., hourly) to balance freshness and performance.</div>
</li>
</ul>
<h3 class="heading-3 ace-line old-record-id-AxNdfcpOHdv2jWc5TqDcp8Bcnnh">3. Model Compatibility</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-A7XFfbgxLdc0jucmEkQcJuhCn4b" data-list="bullet">
<div><strong>Check Model Support</strong>: Not all local models are fully compatible with AnythingLLM. Refer to the official documentation to confirm which models work with the platform (Ollama models are generally well-supported).</div>
</li>
<li class="ace-line ace-line old-record-id-DWeOfy7TEdQwu0c4lfOcq418njg" data-list="bullet">
<div><strong>API Rate Limits</strong>: When using hosted models, be aware of API rate limits (e.g., OpenAI’s token limits per minute). Adjust your usage or upgrade your API plan if you encounter rate-limiting errors.</div>
</li>
</ul>
<h3 class="heading-3 ace-line old-record-id-A3AQfvqyPdT261cpeCjcHTWqnpv">4. Troubleshooting Common Issues</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-LHObfjko7deIeucEw8wc9yOFnOd" data-list="bullet">
<div><strong>Docker Container Won’t Start</strong>: Ensure Docker is running, and the port you’re using isn’t already in use. Check the container logs with <code>docker logs &lt;container_id&gt;</code> for errors.</div>
</li>
<li class="ace-line ace-line old-record-id-E1lkfNAuzd8tUXckYB4c4vqCntc" data-list="bullet">
<div><strong>Chat Responses Are Inaccurate</strong>: Verify that your documents are properly indexed (check the &#8220;Knowledge Sources&#8221; tab for indexing status). Try reuploading documents or switching to a more powerful model.</div>
</li>
<li class="ace-line ace-line old-record-id-HRPDf7BDyddoPfcH8kDc2vBonTh" data-list="bullet">
<div><strong>Model Connection Errors</strong>: For local models, ensure Ollama (or other model servers) is running and accessible. For hosted models, confirm your API key is valid and not expired.</div>
</li>
</ul>
<h3 class="heading-3 ace-line old-record-id-HV0KfxcJWd112xc2qDgcNc62nOd">5. Maintenance &amp; Updates</h3>
<ul class="list-bullet1">
<li class="ace-line ace-line old-record-id-H4EtfFj3hdRaIqcRHpwcaqMwnAd" data-list="bullet">
<div><strong>Update the Platform</strong>: Regularly update the AnythingLLM Docker image to get the latest features and bug fixes: <code>docker pull mintplexlabs/anythingllm:latest</code> followed by restarting the container.</div>
</li>
<li class="ace-line ace-line old-record-id-U9N4fhiC6dNLvJcu1W6c0vR8nmc" data-list="bullet">
<div><strong>Monitor Resource Usage</strong>: Keep an eye on server CPU, memory, and storage usage to ensure the platform runs smoothly. Use tools like Docker Stats or Prometheus for monitoring.</div>
</li>
</ul>
