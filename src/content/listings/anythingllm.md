  <h2 class="ace-line ace-line old-record-id-WJ36dN6q8o9jm6xxTwCcNRxPnRF">AnythingLLM 是什么？</h2>

  <div class="ace-line ace-line old-record-id-EchRfbao3dAogDcm2xJckJLMnIg">AnythingLLM 是一个开源平台，帮助团队使用本地或托管模型构建私有 AI 工作区。它提供实用且易用的解决方案，支持文档对话、整合多种知识源，并在自托管环境中运行 AI 助手，减少对封闭 SaaS（软件即服务）工具的依赖。无论是注重隐私的团队，还是希望更自主掌控 AI 工作流程的用户，AnythingLLM 都能在功能性与数据自主权之间取得平衡。</div>

  <h2 class="heading-2 ace-line old-record-id-YBd2fNqoKddlUscvVN8cKDRLn5s">核心功能与能力</h2>

  <div class="ace-line ace-line old-record-id-TAAQfI3OrdvZaFcAj0YcbEsbnse">AnythingLLM 为现代用户和团队提供了一套全面的 AI 工具，覆盖实际应用场景：</div>

  <ul class="list-bullet1">

  <li class="ace-line ace-line old-record-id-WLUwfePo8dwrkUc6bNQczqoMnah" data-list="bullet">

  <div><strong>私有文档对话</strong> – 创建专属工作区，上传文件和知识源后即可与之对话，获得准确且上下文相关的答案，适用于内部文档、研究资料或机密数据。</div>

  </li>

  <li class="ace-line ace-line old-record-id-LE6TfEguNdmPFCc5QYGc66QjnEe" data-list="bullet">

  <div><strong>支持本地与托管模型</strong> – 无缝集成 Ollama、兼容 OpenAI 的 API 及其他模型后端，灵活选择本地模型（隐私性最高）或托管模型（使用更便捷）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-XVv5fmh6UdGd1ZcuNNecsxzYnBf" data-list="bullet">

  <div><strong>RAG 就绪架构</strong> – 专为检索增强生成（RAG）工作流设计，可从企业知识库和内部文档中高效检索信息，提升 AI 回答的准确性。</div>

  </li>

  <li class="ace-line ace-line old-record-id-KXqgfzjqIdyVzaclmB2cniSFngb" data-list="bullet"><div><strong>自托管部署</strong> – 适合对数据隐私敏感的团队，可部署在自己的服务器或云基础设施上，将敏感信息保留在内部，实现完全掌控。</div>

  </li>

  <li class="ace-line ace-line old-record-id-O9hTfjIW5dtJDvc4TvacHsQpnZe" data-list="bullet">

  <div><strong>多用户工作区设计</strong> – 将AI助手、数据源和项目分入独立工作区，方便团队协作、管理权限，并专注于特定任务。</div>

  </li>

  <li class="ace-line ace-line old-record-id-ENYhfQboQdYd4VcgbLuc2BEIn4g" data-list="bullet">

  <div><strong>智能体与工具扩展</strong> – 作为构建更广泛内部AI助手系统的坚实基础，可根据需求增长添加自定义智能体并集成更多工具来扩展功能。</div>

  </li>

  </ul>

  <h2 class="heading-2 ace-line old-record-id-TPWCfX3gxdsy8PczvQgcWy4lnbq">定价方案</h2>

  <div class="ace-line ace-line old-record-id-RgA9fCZG3dHXJhcYcLDcVzkNnYe">AnythingLLM完全开源且免费部署。实际使用成本取决于三个关键因素：托管环境（如本地服务器、AWS/Azure/GCP等云服务商）、存储用量（用于上传文档和模型数据），以及使用本地模型（免费，但需要硬件资源）还是连接付费API（如OpenAI、Anthropic）——后者会产生相应使用费用。</div>

  <h2 class="heading-2 ace-line old-record-id-C4oGfEUpid4tNwc2EZicejRqn9g">谁适合使用AnythingLLM？</h2>

  <div class="ace-line ace-line old-record-id-QxCKfKkhZd7NFgcnmc3c5InCnSY">AnythingLLM特别适合以下用户：</div>

  <ul class="list-bullet1">

  <li class="ace-line ace-line old-record-id-OSzefgUWDd0edmcRZ1ScWEvUn9c" data-list="bullet">

  <div>希望构建内部知识助手、又不想承担封闭SaaS工具高成本的初创公司和中型企业（SMB）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-HxIcfFQvkd0Z3Mcs2Grcey5dnvh" data-list="bullet">

  <div>需要集中管理并查询内部文档、政策或流程指南的内部运营（ops）团队。</div>

  </li>

  <li class="ace-line ace-line old-record-id-J2MyfhgBNdrqgCcHZoBc8NgMnGc" data-list="bullet"><div>注重隐私的机构（如医疗、金融、法律行业）需要处理敏感数据，并要求完全掌控信息的存储和处理位置。</div>

  </li>

  <li class="ace-line ace-line old-record-id-UCwZfFYZBdCzYTcAJzgc4oQmnJv" data-list="bullet">

  <div>自托管爱好者和开发者，希望在不牺牲定制性或控制权的前提下，获得一个实用、用户友好的界面，用于文档问答和基于检索的AI工作流。</div>

  </li>

  </ul>

  <h2 class="heading-2 ace-line old-record-id-H5qCfvDOidxrDDcBqdUcOtkSn8K">AnythingLLM 与 Open WebUI 和 PrivateGPT 的对比</h2>

  <div class="ace-line ace-line old-record-id-AUrWfgxrCdRNYoc19pJcIwo7n4b">这三款工具都专注于私有AI和自托管，但它们的核心定位和使用场景有所不同：</div>

  <ul class="list-bullet1">

  <li class="ace-line ace-line old-record-id-WzD0fzG4TdpMZvcyW7Xcp3Xandg" data-list="bullet">

  <div><strong>AnythingLLM</strong>：侧重于<em>团队协作</em>、强大的RAG工作流和广泛的模型兼容性。它被设计为一个面向团队的一体化工作空间，在易用性、隐私和功能之间取得平衡。</div>

  </li>

  <li class="ace-line ace-line old-record-id-WeZKf9Mv2dblnocIz3wcXcSxn3e" data-list="bullet">

  <div><strong>Open WebUI</strong>：主要是一个用于与本地模型聊天的用户友好界面。它在简单的单用户本地模型交互方面表现出色，但缺乏AnythingLLM的团队工作空间和RAG功能。</div>

  </li>

  <li class="ace-line ace-line old-record-id-WanqfcsfCdrJTVcQbgbcS4vFnph" data-list="bullet">

  <div><strong>PrivateGPT</strong>：专注于私有文档推理和本地RAG。它适合需要基本文档问答的个人用户或小团队，但在多用户协作或工具扩展方面灵活性较低。</div>

  </li>

  </ul>

  <div class="ace-line ace-line old-record-id-F3qffZvaqdfFRYcf8cTcB54ynof">对于需要在易用性、自托管控制权和知识库工作流之间取得平衡的团队，AnythingLLM是最具吸引力的选择。</div>

  <h3 class="heading-3 ace-line old-record-id-HRKJfcEeVdXKbRcpxxucksA8nn8">1. 部署 AnythingLLM</h3>

  <div class="ace-line ace-line old-record-id-SeG0fad2mdmYT5cMeXIclRDFnhf">使用 Docker 是部署 AnythingLLM 最简单的方式。按以下步骤操作：</div>

  <ol class="list-number1" start="1">

  <li class="ace-line ace-line old-record-id-Elj7fW57cdfg9AcJSgYcdovbnMc" data-list="number">

  <div>打开命令行终端，拉取官方 AnythingLLM Docker 镜像：<code>docker pull mintplexlabs/anythingllm:latest</code></div>

  </li>

  <li class="ace-line ace-line old-record-id-Jn4xfCMp9dUjkLcUAD5csBKxn7b" data-list="number">

  <div>创建一个数据卷，用于在容器重启后保留数据（工作区、文档、设置）：<code>docker volume create anythingllm_data</code></div>

  </li>

  <li class="ace-line ace-line old-record-id-JB6kfMAYFdDkWhcJ8mLcQYutn8c" data-list="number">

  <div>运行 Docker 容器（将 <code>YOUR_PORT</code> 替换为你想要使用的端口，例如 3000）：<code>docker run -d -p YOUR_PORT:3000 -v anythingllm_data:/app/data mintplexlabs/anythingllm:latest</code></div>

  </li>

  <li class="ace-line ace-line old-record-id-VCW2fWlt6dFsWlcBuF1ceBTonjh" data-list="number">

  <div>打开浏览器，访问 <code>http://localhost:YOUR_PORT</code>（或你的服务器 IP 地址加端口）。系统会提示你创建管理员账户，之后即可进入平台。</div>

  </li>

  </ol>

  <h3 class="heading-3 ace-line old-record-id-Kk10f89cjdynsycCWUacPmeqntd">2. 创建工作区</h3>

  <ol class="list-number1" start="1">

  <li class="ace-line ace-line old-record-id-IzsWfchzAdKfuScCk1vckNqAnMh" data-list="number">

  <div>登录后，点击右上角的“创建工作区”按钮。</div>

  </li>

  <li class="ace-line ace-line old-record-id-SkL7fnu4qdqUwZc1gYKc1yapn1g" data-list="number"><div>为工作区输入名称（例如“营销团队文档”）和简短描述（可选）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-BITifeg66dQHRzc68vxc02EInZd" data-list="number">

  <div>点击“创建”完成工作区设置。系统会跳转到工作区仪表盘。</div>

  </li>

  </ol>

  <h3 class="heading-3 ace-line old-record-id-B4V4fgVBVdKzfScxQ2XcXnY3nfc">3. 添加知识源（文档）</h3>

  <ol class="list-number1" start="1">

  <li class="ace-line ace-line old-record-id-FXP3fQpUodsw6dcznAEcRAlJnec" data-list="number">

  <div>在工作区中，点击“添加知识源”按钮。</div>

  </li>

  <li class="ace-line ace-line old-record-id-VuqYfXdMIdGQCSclCVxcYFvQn6c" data-list="number">

  <div>选择要添加的知识源类型：</div>

  <ol class="list-number2">

  <li class="ace-line ace-line old-record-id-P481fpDexdzgr0c61Tuc8UOEnSh" data-list="bullet">

  <div><strong>上传文件</strong>：支持 PDF、DOCX、TXT、Markdown 等常见文档格式。拖拽文件或点击上传。</div>

  </li>

  <li class="ace-line ace-line old-record-id-Zr6Nfu2XBdxpvWckV3dcJvd7nke" data-list="bullet">

  <div><strong>连接 API</strong>（可选）：通过 API 关联外部知识源（如 Notion、Confluence），实现自动同步。</div>

  </li>

  </ol>

  </li>

  <li class="ace-line ace-line old-record-id-QFOEfWECOdCldVcUhHWcRP63nDh" data-list="number">

  <div>上传文件后，AnythingLLM 会处理并建立索引（根据文件大小和数量，可能需要几分钟）。</div>

  </li>

  </ol>

  <h3 class="heading-3 ace-line old-record-id-YyxcfZ9HfdIL2jcON80cvKubn2C">4. 配置 AI 模型</h3>

  <ol class="list-number1" start="1">

  <li class="ace-line ace-line old-record-id-ITaNfkr8hdiYOVcM8tNcMkYjnAd" data-list="number">

  <div>进入工作区的“设置”选项卡。</div>

  </li>

  <li class="ace-line ace-line old-record-id-Aq8Sfk8F6dSqc0cwUtrcfgFanAg" data-list="number">

  <div>在“模型配置”下，选择偏好的模型后端：</div>

  <ol class="list-number2">

  <li class="ace-line ace-line old-record-id-P8Tmf3qygdOMHcczlk4cgLGpnRh" data-list="bullet">

  <div><strong>本地模型</strong>：如果使用 Ollama，输入 Ollama 服务器 URL（例如 <code>http://localhost:11434</code>），然后选择要使用的模型（例如 llama3:8b）。</div>

  </li><li class="ace-line ace-line old-record-id-FyYXfHdwSdTpaDcA78GcwEDDnyf" data-list="bullet">

  <div><strong>托管模型</strong>：输入你的 OpenAI、Anthropic 或其他兼容服务的 API 密钥，然后选择模型（例如 gpt-4o）。</div>

  </li>

  </ol>

  </li>

  <li class="ace-line ace-line old-record-id-A58Hfn1Afd6bOGcgfbicw1V7nsg" data-list="number">

  <div>点击“保存设置”以应用你选择的模型。</div>

  </li>

  </ol>

  <h3 class="heading-3 ace-line old-record-id-F0y9foYLAdDGo7c39s8chSVjnYZ">5. 与你的文档聊天</h3>

  <ol class="list-number1" start="1">

  <li class="ace-line ace-line old-record-id-OLeQfX46WdCj1LcjlfAcjheInyg" data-list="number">

  <li class="ace-line ace-line old-record-id-Ms5qfj7MQd3YFVcs4uFcR7yznPb" data-list="number">

  <div>输入与已上传文档相关的问题（例如：“第三季度营销报告中的关键要点是什么？”）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-CY3CfrEIKd2kxgcDHAzcZgNinNc" data-list="number">

  </li>

  <li class="ace-line ace-line old-record-id-VGQlfKTd7dhUNxcJwkbcfFLpngc" data-list="number">

  <div>你可以通过提出后续问题继续对话，也可以从“知识源”侧边栏中选择其他文档来切换。</div>

  </li>

  </ol>

  </li>

  <li class="ace-line ace-line old-record-id-Po1Yf6vsndSbJpcr0pcc5rvsnFg" data-list="number">

  </li>

  </ol>

  <h2 class="heading-2 ace-line old-record-id-DgywfAZRedtuFecHIvrcagCEnve">重要提示与最佳实践</h2><h3 class="heading-3 ace-line old-record-id-JXGgfqhNcdLhY1cGaiFcxEdcnIg">1. 隐私与数据安全</h3>

  <ul class="list-bullet1">

  <li class="ace-line ace-line old-record-id-LbnIfAg4idKCnZc7l3BcvDCXnPd" data-list="bullet">

  <div><strong>自托管责任</strong>：如果你在自己的服务器上部署 AnythingLLM，请确保服务器已做好安全防护（如防火墙、加密），以保护敏感数据。除非必要，避免将平台暴露在公共网络上。</div>

  </li>

  <li class="ace-line ace-line old-record-id-IL5sfLZEXd2YHOcJtS2cIWPSnmx" data-list="bullet">

  <div><strong>API 密钥保护</strong>：使用托管模型（如 OpenAI）时，切勿公开分享你的 API 密钥，也不要将其存储在未加密的文件中。使用环境变量或平台内置的密钥管理功能来保障密钥安全。</div>

  </li>

  <li class="ace-line ace-line old-record-id-TiNYftZx6dFlpIcdZ85cBP76n4f" data-list="bullet">

  <div><strong>数据保留</strong>：定期备份工作区数据（通过 Docker 卷或平台导出功能），防止数据丢失。删除不再使用的文档或工作区，以降低存储成本并提升性能。</div>

  </li>

  </ul>

  <h3 class="heading-3 ace-line old-record-id-UiysfCsQmdgebdcVeDBcKZ6fnif">2. 性能优化</h3>

  <ul class="list-bullet1">

  <li class="ace-line ace-line old-record-id-CyR9fvMPcddtHacQl6ucq5wpnGe" data-list="bullet">

  <div><strong>本地模型的硬件要求</strong>：运行本地模型（如 llama3:70b）需要较高的 CPU/GPU 资源。为保证流畅运行，建议使用配备独立 GPU 的机器（NVIDIA GPU 推理速度更快）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-OlNefXnledpbyzcUdCrclHl1n6D" data-list="bullet">

  <div><strong>文档大小限制</strong>：避免上传超大文件（如 100MB 以上的 PDF），否则可能拖慢索引和聊天响应速度。上传前将大文档拆分为较小的片段。</div>

  </li>

  <li class="ace-line ace-line old-record-id-ONkOfnUv0d4MuGcJYuzcHdHwntc" data-list="bullet">

  <div><strong>索引频率</strong>：如果你在同步外部知识源（如 Notion），请设置合理的同步频率（如每小时一次），在数据新鲜度和性能之间取得平衡。</div>

  </li>

  </ul>

  <h3 class="heading-3 ace-line old-record-id-AxNdfcpOHdv2jWc5TqDcp8Bcnnh">3. 模型兼容性</h3>

  <ul class="list-bullet1"><li class="ace-line ace-line old-record-id-A7XFfbgxLdc0jucmEkQcJuhCn4b" data-list="bullet">

  <div><strong>检查模型支持</strong>：并非所有本地模型都能与 AnythingLLM 完全兼容。请查阅官方文档，确认哪些模型可在该平台上运行（Ollama 模型通常支持良好）。</div>

  </li>

  <li class="ace-line ace-line old-record-id-DWeOfy7TEdQwu0c4lfOcq418njg" data-list="bullet">

  <div><strong>API 速率限制</strong>：使用托管模型时，请注意 API 速率限制（例如 OpenAI 每分钟的令牌限制）。若遇到限流错误，可调整使用方式或升级 API 套餐。</div>

  </li>

  </ul>

  <h3 class="heading-3 ace-line old-record-id-A3AQfvqyPdT261cpeCjcHTWqnpv">4. 常见问题排查</h3>
