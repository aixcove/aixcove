<h2>What Is ZCode?</h2>
<p>ZCode is an agentic development environment from Z.ai built for long-running software engineering tasks. Instead of acting like a traditional editor with a small chat sidebar, ZCode puts a first-party coding agent at the center of the workflow so developers can describe a goal and let the agent plan, edit files, run commands, preview changes, review diffs, and continue across a longer task.</p>
<h2>Key Features</h2>
<ul>
<li><strong>Agentic development workspace</strong> for coding, debugging, testing, preview, and change review.</li>
<li><strong>Long-task execution</strong> that keeps requirements, files, terminal output, browser context, permissions, and Git state inside one continuous task.</li>
<li><strong>Remote control</strong> through desktop, mobile Remote, and bot channels such as Feishu and WeChat.</li>
<li><strong>Safe execution controls</strong> for sensitive commands, file changes, and higher-permission actions.</li>
<li><strong>Model flexibility</strong> through Z.ai, BigModel, API keys, enterprise model channels, or approved self-hosted services.</li>
</ul>
<h2>Who Should Use ZCode?</h2>
<p>ZCode is a strong fit for developers and technical teams that want an AI coding environment designed around longer engineering loops: implementing features, fixing bugs, running verification, reviewing changes, and continuing work from another device. It is especially relevant for teams already evaluating GLM coding models, Z.ai accounts, or agent-first development tools.</p>
<h2>Pricing and Access</h2>
<p>The ZCode application is free to use, but developers need an API key, a supported model service plan, an enterprise model channel, or an approved self-hosted model service for agent execution. Check the official ZCode documentation for the latest connection and quota details.</p>
