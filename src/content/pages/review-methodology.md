<p>Every tool page and comparison on AIX Cove follows the same editorial process. This page explains exactly how we research, verify, and update — so you can judge our conclusions for yourself.</p>

<h2>What we cover</h2>
<p>AIX Cove publishes three types of content:</p>
<ul>
<li><strong>Tool listings</strong> — a structured profile of one AI tool: what it does, what it is good at, how to run it, limits, and how it relates to alternatives.</li>
<li><strong>Comparisons</strong> — head-to-head pages (e.g. Jules vs OpenHands) built around workflow fit, not feature checklists.</li>
<li><strong>Guides and lists</strong> — curated selections for a specific job, budget, or deployment model.</li>
</ul>

<h2>Sources come first</h2>
<p>Every factual claim — pricing, licensing, platform support, release status — is checked against the vendor's own materials: official docs, pricing pages, changelogs, and GitHub repositories. When official sources conflict or a vendor changes pricing without an announcement, we say so instead of averaging the numbers.</p>
<p>Third-party reviews are used only as secondary context, never as the basis for a fact. Each page lists its key official sources at the bottom.</p>

<h2>Hands-on when we can, honest when we can't</h2>
<p>We install and use tools whenever a public trial, open-source release, or free tier makes that possible — installation path, CLI ergonomics, and failure modes are exactly the things spec sheets don't show. When we could not test something (closed beta, enterprise-only plan, usage costs beyond a reasonable budget), the page says so explicitly. We do not invent first-person experience we don't have.</p>

<h2>What we check</h2>
<ul>
<li><strong>Identity and status</strong> — who builds it, open-source or proprietary, license, and whether it is GA, beta, or deprecated.</li>
<li><strong>Capabilities</strong> — what the tool actually does at its core, verified against docs rather than marketing copy.</li>
<li><strong>Pricing</strong> — current tiers, free-tier limits, and the real cost of a typical workflow, each tagged with the date we verified it.</li>
<li><strong>Setup and operation</strong> — install steps, platform requirements, and the operational knowledge the tool assumes.</li>
<li><strong>Limitations</strong> — known constraints, security considerations, and scaling caveats stated by the vendor or observable in practice.</li>
<li><strong>Positioning</strong> — which alternatives it trades blows with, and who each one suits better.</li>
</ul>

<h2>How comparisons are written</h2>
<p>Our comparisons open with a quick verdict, then break down the real differences: workflow fit, setup, pricing, and security. We end with role-based recommendations ("pick X if you…, Y if you…") instead of a single crowned winner, because tool choice is mostly a function of your constraints.</p>

<h2>Updates and corrections</h2>
<p>AI tools change fast. Pricing and feature claims carry a <em>verified as of</em> date, and pages are revisited when a vendor ships a major release. If you spot an outdated number or a broken fact, <a href="/contact-us/">tell us</a> — corrections ship quickly and are not buried.</p>

<h2>Editorial standards</h2>
<ul>
<li>Official sources first; marketing claims are verified or flagged.</li>
<li>No invented testing; untested claims are labeled.</li>
<li>No pay-to-play placements; featured badges are editorial.</li>
<li>Affiliate or sponsored content, if ever introduced, will be labeled inline.</li>
</ul>
