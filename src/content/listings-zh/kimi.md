<h2>Kimi 是什么</h2>
<p>Kimi 是月之暗面推出的 AI 助手，常用于中文和中英双语环境中的阅读、写作、研究整理与日常问答。它的模型和产品能力变化很快，单看宣传中的上下文数字意义有限。更值得测试的是，它能否把手里的资料变成一份可以回到原文核对的结果。</p>
<p>2026 年 9 月的官方口径：Kimi 对话产品运行在 Kimi K2.6 上，原生多模态，支持文本、图片与视频输入。旗舰模型 Kimi K3 于 2026 年 7 月发布，2.8 万亿参数、开放权重，100 万 token 上下文；编程有 Kimi K2.7 Code。旧版 K2 系列已于 2026 年 5 月停维护，仍用 kimi-k2 系列 ID 的教程已过时。</p>

<h2>长上下文的实际意义</h2>
<p>上下文容量是 Kimi 最主打的卖点，数字也真实。K2.6 提供 256K token 上下文，一次对话足够装下几百页中英文材料；K3 扩展到约 100 万 token，但只对最高档会员开放。这些是文档写明的单次请求窗口，不等于召回保证：再流畅的摘要也可能漏掉埋在后面的例外条款。把它当作复核的余量，而不是替代品。</p>

<h2>适合的工作</h2>
<ul>
<li><strong>中文知识工作</strong>读报告、整理会议材料、起草沟通内容、梳理技术概念。中文表达是被肯定最多的方面。</li>
<li><strong>双语协作</strong>对照中英文资料，形成双语提纲，标记必须人工决定的术语。</li>
<li><strong>长文档预处理</strong>列出章节结构、决策点、缺失附件和需要重点复核的段落。</li>
<li><strong>多模态审阅</strong>K2.6 和 K3 都能直接读图片和视频，扫描件、截图或录像可以和文本文件放在同一次对话里讨论。</li>
<li><strong>研究准备</strong>把宽泛问题拆成检索计划和证据清单。</li>
</ul>

<h2>处理长文档的实用方法</h2>
<p>不要一次上传大文件后直接要结论。先让 Kimi 列文件结构和可能遗漏的材料；第二步对关键结论给出原文位置；最后才写摘要或翻译。这样能尽早发现漏页，也不容易被流畅文字掩盖证据不足。双语任务先给术语表，明确产品名、法律术语和人名以哪种语言为准，拿不准的翻译让它标记而不是自作主张。联网研究时把一手资料和评论分开要，重要结论仍应打开来源核对。</p>

<h2>价格：会员与开放平台</h2>
<p>消费侧有免费额度，之上是会员。2026 年 9 月帮助中心口径为四档：49、99、199、699 元每月。会员功能，包括 Agent 任务、Kimi Code 和 K2.6 对话，共用一个额度池。国际版同期列出免费 Adagio 档和 19、39、99、199 美元的付费档。月之暗面在 2026 年年中曾因算力紧张暂停新用户订阅，档位可能波动。</p>
<p>开放平台 API 按量计费。2026 年 9 月每百万 token：kimi-k3 输入 3 美元、输出 15 美元，缓存命中输入 0.30 美元；kimi-k2.6 输入 0.95 美元、输出 4.00 美元；kimi-k2.7-code 与 K2.6 相同。批量六折。K3 价格接近海外前沿模型，K2.6 则是同档里单价较低的模型，原型用 K3、大批量跑 K2.6 是常见的成本组合。</p>

<h2>适合谁与不适合谁</h2>
<p>以中文为主的读者、写作者和研究者，对照中英文资料的双语团队，处理长文档和混合材料的分析师，以及希望聊天产品、开放平台和 Kimi Code 相互衔接的国内开发者，都是典型用户。主要需要英文编程智能体的，用 Codex 或 Claude 更成熟；组织不允许把资料交给境外消费级 AI 服务的，或希望不经核对直接引用结论的，同样不合适。</p>

<h2>公开反馈与限制</h2>
<p>公开讨论里，用户常提到 Kimi 的中文表达和长材料阅读能力，中英混合工作流的使用者也喜欢多一个选择。常见提醒包括地区可用性、用量限制变化，以及摘要很顺却仍可能遗漏例外条款。涉及商业、法律、医疗和个人资料时，应按组织的数据规则处理；开放平台对企业客户提供零数据保留选项。日常开发更适合 <a href="/zh/listing/codex/">Codex</a>、<a href="/zh/listing/claude/">Claude</a> 或专门的 AI 编程环境，尽管 Kimi Code 进步很快。</p>
