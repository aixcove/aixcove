<h2>Perplexity 是什么？</h2>
<p>它把大语言模型与实时搜索结合，每个回答都附可点开核对的来源。到 2026 年它已超出搜索本身：多步骤的 Research 模式生成结构化研究报告，名为 Computer 的智能体能创建文件、数据面板和小应用，但核心价值仍是快速研究加上看得见的溯源。</p>
<p>它不是学术级的引文工具。它比浏览器翻找更快地综合多个来源，但引文只指向页面，不等于事实已验证，把任何说法当作定论前仍应打开来源核对。</p>
<h2>核心功能</h2>
<ul>
<li><strong>带引文的答案</strong>：所有套餐的每条回复都有编号来源链接，免费层也是。</li>
<li><strong>实时网页搜索</strong>：拉取全网最新信息，专注模式可限定到学术论文、Reddit、YouTube、新闻或指定域名。</li>
<li><strong>模型编排</strong>：为每次查询挑合适的模型，付费档可逐条指定偏好模型。</li>
<li><strong>Pro Search 与 Research</strong>：多步模式，先规划、反复搜索，再综合结果。</li>
<li><strong>Computer</strong>：付费档的智能体，执行报告、数据收集、应用搭建等较长任务，按额度计费。</li>
</ul>
<h2>定价：免费、Pro 与 Max（2026 年 9 月核实）</h2>
<p><strong>免费层</strong>包含几乎不限量的 Quick 搜索且带引文，轻度研究够用。限制在别处：帮助中心当前对比表写明约每天 3 次 Pro Search、约每月 1 次 Research 查询，另有少量文件上传，没有模型选择和高级数据源。这些数字会变动，较旧的帮助页仍写着每天 5 次。</p>
<p><strong>Pro 为每月 $20，年付折合每月 $17。</strong>它把 Pro Search 提升到按周的常规用量额度，增加每月的 Research 与文件应用创建次数，解锁高级模型并可逐条选择（官方当前阵容包括 Claude Sonnet 5、Gemini 3.1 Pro、GPT-5.6、Sonar 2 等），文件上传提升到每个 Space 约 50 个，另加图片视频生成、PitchBook 和 Statista 等付费数据源与优先支持。新订户一次性获赠 4,000 Computer 额度，之后不含月度额度。<strong>Max 为每月 $200</strong>（年付 $167），含每月 10,000 额度和最高用量上限。企业版走销售询价，学生和教育者有折扣价。</p>
<h2>Pro Search、Research 与 Computer 的实际差别</h2>
<p>Quick 搜索做一次检索并总结，处理简单事实查询足够。Pro Search 会先规划、多次搜索再合并结果，对比较类和模糊查询更有用。Research（原 Deep Research）运行更长的调查并输出结构化报告，免费层约每月仅 1 次。旧版 Labs 功能已并入文件应用创建与 Computer。Computer 按额度计费：100 额度等于 $1，轻量任务约消耗 15 到 70 额度，额度耗尽时任务会暂停而非失败。</p>
<h2>与 ChatGPT Search、Google 的对比</h2>
<p>开启搜索的 ChatGPT 是最接近的对手：作为通用助手和长文写作工具更强，但引文的出现并不总是稳定。Perplexity 从免费层起就做到每个答案引文优先，专注模式与 Research 也是为查证型工作调校的。Google 索引最深，让你自己判断来源，代价是综合要自己完成。实用分工：带引文的快速答案用 Perplexity，写作用 ChatGPT，亲自检查一手结果用 Google。</p>
<h2>API 定价</h2>
<p>Perplexity 在官方文档中公开了 API 费率（2026 年 9 月核实）。Search API 每千次请求 $5，不收 token 费。Sonar 系列按 token 计费：Sonar 输入输出均为每百万 $1，Sonar Pro 为 $3 和 $15，Sonar Reasoning Pro 为 $2 和 $8，请求费随搜索上下文规模上浮。Agent API 按各模型公开费率收费，另加工具费，例如每次网页搜索 $0.0025。Sonar 对话接口将于 2026 年 9 月 27 日停用并由 Agent API 取代，迁移要提前做预算。</p>
<h2>限制与取舍</h2>
<p>答案质量取决于检索到的来源，引文并不代表权威；免费层的额度会很快打断重度研究，Pro Search 的额度是按周的区间而非固定数字。产品为答案而生，不擅长深度交互写作和长期记忆。Perplexity 已多次下调额度，本文数字只是当前快照。</p>
<h2>谁适合用 Perplexity？</h2>
<p>它适合研究员、分析师、学生、记者，以及想快速拿到有来源答案、又不想开十个标签页的人；免费层足够轻度使用。它不太适合主要需要写作或编程伙伴、逐字引用一手文档，或依赖稳定配额的人。要用你自己的文件做文档级问答，可对比<a href="/zh/listing/notion-ai/">Notion AI</a>。</p>
