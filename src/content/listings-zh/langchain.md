<h2>什么是 LangChain？</h2>
<p>LangChain 是目前使用最广的开源框架，专门用来在大语言模型之上搭建应用。它位于你的产品和模型供应商之间，提供可复用的部件：提示词模板、工具调用、记忆、检索，以及智能体的执行循环。现在有两块内容归在同一屋檐下：一个是你自己运行的开源框架，另一个是 LangSmith，一个用于追踪、评估和部署智能体的托管平台。</p>
<p>选 LangChain 本质上是选控制权。它不是租来的成品，而是你导入进来、按自己需求改的代码库。你可以保留自己的代码、随意换模型供应商，也能部署到自己的服务器上。代价是这些接线、升级路径和版本升级带来的接口兼容问题，都要你自己负责。</p>
<p>它适合那些已经确定要自己搭智能体架构的团队。如果你只是想要一个开箱即用的对话助手，一个成品软件会让你更快上手。</p>
<h2>核心功能</h2>
<ul>
<li><strong>可组合的链</strong> — 把多次模型调用和工具步骤串成一条可单独测试的流水线</li>
<li><strong>智能体循环</strong> — 让模型自己决定下一步调用哪个工具，一直循环到任务结束</li>
<li><strong>检索增强</strong> — 接入向量库和文档加载器，得到有依据、可引用的答案</li>
<li><strong>记忆与状态</strong> — 在多轮对话和智能体执行中保存历史与上下文</li>
<li><strong>LangGraph</strong> — 基于图的结构化编排，适合有状态、多步骤且流程明确的智能体</li>
<li><strong>生态</strong> — 数据库、API、模型供应商的上百种集成，以及庞大的社区</li>
</ul>
<h2>定价</h2>
<p>框架本身免费，采用 MIT 开源协议（截至 2026 年 8 月约有 14.5 万星标），你永远不需要为使用这些代码付费。钱主要在 LangSmith 这个托管观测与评估产品上。开发者版每个席位每月 0 美元，含 5000 条基础追踪记录，超出按量付费。Plus 版每个席位每月 39 美元，含 10000 条基础追踪记录，席位不限。企业版采用定制报价，支持私有化或混合部署。在固定套餐之外，用量按单位计费：1 个 LangChain 计算单元（LCU）1.50 美元，1 个存储单元（LSU）1.00 美元。最新价格以官方 <a href="https://www.langchain.com/pricing" target="_blank" rel="noopener noreferrer">LangChain 定价页</a>为准。</p>
<h2>局限与取舍</h2>
<p>框架迭代很快。跨大版本的接口和包名经常变化，一年前写的代码可能得返工。学习曲线也不低，这些抽象很强但并不直观，新手常常绕了一圈，反而比不上直接调用几次 API 来得省事。对小型内部工具来说，这种额外的复杂性可能得不偿失。</p>
<p>成本也未必为零。LangSmith 按追踪记录和计算量收费，一个繁忙的生产级智能体很快会超出赠送的配额，所以观测方面的开销需要单独预算。而且架构是你自己拼起来的，质量把控如评测和护栏，更多要靠你自己，而非供应商。</p>
<h2>谁适合用 LangChain？</h2>
<p>把 AI 融进现有产品里的后端工程师获益最大，因为它能嵌入你已经掌控的代码。数据工程师需要把检索接进内部助手，在这里能用到文档和向量库这一层。要在同质化模型之上做出差异化的 AI 初创公司，会把它当作地基。跑在私有网络或受监管环境里的团队，会自托管框架和 LangGraph，而不是把数据交给第三方。</p>
<p>它不适合想要今天就能拿到成品助手、或者没有开发者来维护自定义代码的人。</p>
