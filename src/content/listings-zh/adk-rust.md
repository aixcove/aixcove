<h2>什么是 ADK-Rust？</h2>
<p>ADK-Rust 是一个专注于生产的 Rust 框架，用于构建 AI 代理，包含用于模型、工具、内存、会话、RAG、实时语音和部署 API 的模块化 crate。</p>
<h2>为什么 ADK-Rust 现在脱颖而出</h2>
<p>该项目具有当前发布势头、实时游乐场，以及对 Python 以外的代码优先代理框架日益增长的兴趣。</p>
<h2>谁应该考虑 ADK-Rust</h2>
<p>需要强类型、模块化和自托管部署选项的构建代理系统的 Rust 开发者</p>
