<h2>什么是 ZCode？</h2>
<p>ZCode 是 Z.ai 推出的智能体开发环境，专为长时间软件工程任务而设计。与传统编辑器加小型聊天侧边栏的模式不同，ZCode 将第一方编程智能体置于工作流的核心位置，让开发者描述目标后，智能体即可规划、编辑文件、运行命令、预览更改、审查差异，并在更长的任务中持续工作。</p>
<h2>主要功能</h2>
<ul>
<li><strong>智能体开发工作区</strong>，支持编码、调试、测试、预览和更改审查。</li>
<li><strong>长任务执行</strong>，将需求、文件、终端输出、浏览器上下文、权限和 Git 状态保持在单一连续任务中。</li>
<li><strong>远程控制</strong>，可通过桌面端、移动端 Remote 以及飞书、微信等机器人渠道操作。</li>
<li><strong>安全执行控制</strong>，针对敏感命令、文件更改和更高权限操作提供保护。</li>
<li><strong>模型灵活性</strong>，支持 Z.ai、BigModel、API 密钥、企业模型渠道或经批准的自托管服务。</li>
</ul>
<h2>谁适合使用 ZCode？</h2>
<p>ZCode 非常适合希望围绕更长工程循环（实现功能、修复错误、运行验证、审查更改以及从另一设备继续工作）来构建 AI 编码环境的开发者和技术团队。对于已在评估 GLM 编程模型、Z.ai 账户或智能体优先开发工具的团队，ZCode 尤其相关。</p>
<h2>定价与访问</h2>
<p>ZCode 应用程序免费使用，但开发者需要 API 密钥、受支持的模型服务套餐、企业模型渠道或经批准的自托管模型服务才能执行智能体操作。请查阅 ZCode 官方文档，了解最新的连接和配额详情。</p>
